# 版本与更新记录

灯塔从 `1.0.0` 开始，只使用三段数字版本。大幅升级递增第一位，新增功能递增第二位，修复和小调整递增第三位；递增前一位时后面的位归零。

## 更新方法

1. 修改 `src/content/releases.json`，把新版本放在数组最前面；保留已有记录。
2. 写清版本、标题、简介和分组变化。文案描述用户可见的实际能力，不直接复制提交日志，也不把未完成、未开放的功能写成已可用。
3. `date` 是发布日（YYYY-MM-DD），未发布时使用 `null`。1.0.0 是首版基线，不补造旧版本记录或发布日期。
4. 执行 `npm run releases:sync`，同步 package.json、package-lock.json 和 CHANGELOG.md。
5. 执行 `npm run releases:check`。`npm run build` 也会先做一致性检查。

通知与 `/updates` 共用这份数据，当前版本取第一项。因此，每个部署显示随代码交付的版本，不会读取其他环境的最新版本。

通知打开或访问更新页后，会在当前浏览器保存已读版本。升级后再次提示；清除浏览器数据或更换浏览器后可能重新提示。不包含账户间同步，浏览器禁用存储时仍可正常查看。

本次代码版本设为 1.0.0，不代表内网已经部署或完成发布验收。正式发布时补充首版日期；部署流程另行建设。
