# 服务核心框架英文版方案：文案与纹样修订设计

## 目标

修订现有《精诚服务核心价值英文选词说明》页面。保留词源、拉丁语对应、思想背景与出处，把文字从整齐但机械的说明稿改成有编辑判断的品牌方案文本；同时处理章节右上角纹样过于独立、像贴上去的问题。

## 已确认方向

- 页面主标题改为“服务核心框架英文版方案”。
- 采用编辑式重写，不降格为宣传口号，也不删减必要考据。
- 五个英文主词保持不变：Truth、Goodness、Beauty、Care、Flourishing。
- 中文正式用词保持不变：求真、尽善、致美、大爱、幸福。
- 现有 14 项来源、词源边界和“概念对应并非直接词根”等限定必须保留。

## 文案编辑规则

1. 删除公式化句式。重点处理反复出现的“不是……而是……”“不只……也……”以及刻意对称的三段式表达。
2. 先说事实，再作判断。词源段交代语言事实；思想背景段说明概念关系；选词段直接给出选择理由和边界。
3. 保留必要限定，但不重复辩护。同一判断只解释一次，不在章节标题、正文和结语中换词重复。
4. 调整句子节奏。长句负责交代考据，短句负责下判断；避免每一段都以总结句收尾。
5. 减少抽象词堆叠。能用“费用、进度、风险、承诺”等具体词时，不写泛化的“价值、关系、路径、实现”。
6. 备选词比较保持简短。说明它适合表达什么，以及为何不足以承担本页中文词义，不写成四项同构的否定清单。
7. 保留英文品牌解释句，并同步调整中文解释，使其像可用于正式方案的定稿文字。

## 页面首屏

- 主标题使用“服务核心框架英文版方案”，不再使用疑问句。
- 导语改为直接说明工作方法：先厘清中文价值在服务现场承担的含义，再选择英语中功能最接近的词。
- 五个中英文标签继续作为首屏索引，不改结构。

## 纹样处理

章节纹样不再以完整方形出现在标题右侧。每章仍保留对应纹样，但将尺寸放大，并让大部分图形越出版心和页面右边缘，只留下局部暗纹进入画面。透明度降低，取消明显旋转，使纹样更接近纸张底纹，而不是独立插图。

移动端只保留更小、更淡的边缘片段，不能压到章节标题、释义或词源摘要。首屏原有盘长纹样也采用同一原则，避免出现完整图案边界。

## 不改动范围

- 不更换五个英文词。
- 不删除来源或降低考据准确性。
- 不改变章节导航、阅读进度、返回顶部和打印功能。
- 不改动其他 HTML 或用户现有未提交文件。

## 验收标准

- 页面主标题准确显示“服务核心框架英文版方案”。
- 五章正文完成逐段编辑，事实、专名、音标、拉丁语和来源编号仍可核对。
- “不是……而是……”等模板句显著减少，段落不再呈现相同节奏和相同收束方式。
- 章节纹样只以越出页面边缘的低透明度片段出现，不形成完整方块。
- 320px 至桌面宽度不产生横向溢出；纹样不遮挡正文。
- 原有结构、内嵌素材、脚本和引用链接继续通过静态检查。
