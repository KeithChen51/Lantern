# 经销商会前预热 H5 v0.3 视觉改版设计

状态：视觉方向与详细设计已确认，等待实施计划。

## 背景

现有会前预热 H5 已具备完整的五题互动、答案改选、价值计分、结果海报生成与保存能力，但视觉仍沿用早期暖米色网格与五色价值体系，未采用《精诚服务视觉识别手册 v0.3》沉淀的色彩、纹样和版式语言。

本次改版采用用户确认的 A 方向“价值纹样叙事”：保留现有内容与交互逻辑，仅重构视觉表现和移动端排版，使 H5 与后续年会物料共享同一套品牌识别。

## 依据

- 现有 Demo：`docs/design/dealer-service-h5-preheat-demo.html`
- 正式手册：`../brand-vi-and-training/brand-vi/精诚服务新版VI手册.html`
- 纹样资产：`../brand-vi-and-training/brand-vi/vi-assets/pattern-backgrounds/`
- 正式手册版本：v0.3，2026-07-07

当通用 HTML 设计规范与上述正式手册冲突时，以《精诚服务视觉识别手册 v0.3》为准。尤其不得把“精诚养车橙”引入精诚服务视觉系统。

## 目标

1. 让封面、答题页和结果海报形成一致的精诚服务视觉语言。
2. 把五个价值词与对应传统纹样建立可感知但克制的联系。
3. 保持题目阅读、答案比较和重新选择的效率，不让纹样抢占正文。
4. 继续交付一个可直接通过 `file://` 打开和分享的自包含 HTML。

## 范围

### 本次包含

- 页面色彩、字体、间距、层级、按钮、选项、反馈和结果海报视觉。
- 封面视觉从旧关键词位图切换为品牌纹样构图。
- 纹样以 Base64 数据资源嵌入 HTML。
- Canvas 生成的 1080×1920 结果海报同步采用 v0.3 视觉语言。
- 320px 至 430px 手机宽度的响应式适配。

### 本次不包含

- 修改五道题、选项、反馈文案或价值映射数据。
- 修改答案改选、计分、并列结果、海报保存等业务逻辑。
- 修改白皮书内容或重新定义白皮书分发地址。
- 把 Demo 改造成 Lighthouse 产品页面或新增后端服务。

## 已批准方向

采用“价值纹样叙事”，核心规则是：一块内容只出现一个主纹样。

- 同一选项映射两个价值时，视觉使用 `option.values[0]` 对应的第一价值纹样。
- 文案仍展示该选项完整的双价值反馈。
- 不叠加两种纹样，不把多个母形融合成复合底图。
- 并列结果统一使用盘长纹，标题保留两个关键词。

## 视觉系统

### 色彩

| 角色 | 色值 | 用法 |
| --- | --- | --- |
| 精诚墨青 | `#183A34` | 手机外框、主要按钮、主结构、重点文字 |
| 烟墨黑 | `#0B130F` | 标题与正文主文字 |
| 宣纸米 | `#F3E9D7` | 页面基础纸色 |
| 纸白 | `#FFFDF8` | 选项和内容承载面 |
| 绢灰 | `#D8D2C8` | 分隔线、进度底轨、次要边界 |
| 玉灰绿 | `#AEBB9E` | 低强度辅助层 |
| 水青蓝 | `#315B6A` | 流程、进度和有限的冷色辅助 |
| 鎏金线 | `#BFA76A` | 细线、章节节奏，画面占比不超过 4% |
| 朱砂印 | `#722912` | 章标、选中标记，画面占比不超过 2% |

纸色与留白占可见面积 60% 以上。移除现有五种高饱和值色和多色渐变进度条，不再用颜色分别编码五个价值。

### 字体

- 标题、题干、结果关键词：宋体序列，优先 `Noto Serif SC`、`Source Han Serif SC`、`Songti SC`、`SimSun`。
- 正文、选项、按钮和辅助说明：`Microsoft YaHei UI`、`Microsoft YaHei`、`Source Han Sans CN`、无衬线字体。
- 不使用装饰性全大写英文标签；现有英文装饰文案改为自然中文或删除。
- 字距固定为 0，不使用视口宽度缩放字体。

### 纹样映射

| 价值 | 页面主纹样 | 语义 |
| --- | --- | --- |
| 求真 | 回纹 | 边界、秩序、依据 |
| 尽善 | 如意纹 | 圆融、善意、稳妥选择 |
| 致美 | 卷草纹 | 生长、比例、章法 |
| 大爱 | 方胜纹 | 连接、伙伴、责任关系 |
| 幸福 | 盘长纹 | 长期陪伴、圆满、持续 |

龟背、莲瓣和水波仍保留在品牌资产中，但本次 H5 为降低视觉发散，只使用上述五种价值主纹样；水波额外用于不承载价值判断的流程进度与章节分隔。

## 页面设计

### 手机预览框架

- 继续保持单一手机端预览，不恢复桌面方案说明区。
- 设计基准为 390×780，适配 320px 至 430px 宽度。
- 手机外框使用精诚墨青平面色，减少现有深色渐变和重阴影。
- 屏幕以纸白和宣纸米为主，取消方格纸背景、彩色光斑和装饰圆形。
- 圆角不超过现有 8px 内容组件上限；手机设备外框可保留设备造型圆角。

### 封面

- 移除现有内嵌关键词拼字位图及其悬浮胶囊标签。
- 盘长纹作为跨价值总结底纹，尺寸约 420 至 520px，透明度 8% 至 10%。
- 纹样从右下边缘向标题区衰减，不穿过标题主笔画。
- 保留现有主标题和说明文案，但改为左对齐的手册式层级。
- “参悟案例 / 5 个判断”改为普通元信息，不使用圆角胶囊。
- 主按钮使用精诚墨青实色、纸白文字，不使用橙色或渐变。

### 答题页

- 顶部保留题号和“诚信经营参悟”，使用水波细线或墨青单色进度前景。
- 题干保持宋体，选项保持黑体；长题目优先保证可读空间。
- 选项使用纸白平面、绢灰细边界和 8px 以内圆角，减少阴影。
- 选中项使用墨青边界与极小面积朱砂标记；未选项降低对比但保持可点击。
- 选中后，反馈区域使用该选项第一价值纹样作为整块暗纹：母形约 240 至 300px、透明度约 15%，从左上向右下渐显。
- 反馈区域与选项列表保持同一信息层级，不形成卡片套卡片。
- 重新选择时立即替换选中样式、反馈纹样和反馈文本，不改变页面尺寸。

### 结果页与海报

- 结果页继续直接展示完整 1080×1920 海报，不新增“生成”或“重新体验”按钮。
- 单一最高分结果使用该价值纹样；并列结果使用盘长纹。
- 关键词以小型朱砂章或章标强调，不再使用彩色圆形徽章。
- 五项得分使用统一墨青与中性色条形结构，最高项以墨青实线和朱砂小标识强化；其余项不分别着五种颜色。
- 理念诠释区使用纸白平面和绢灰分隔，不使用条形码、英文装饰标签或重阴影卡片。
- 底部保留“保存服务关键词海报”和“查看服务理念升级白皮书”。主次按钮分别使用墨青实色和纸白描边。

## 数据与状态

### 保持不变

- `questions` 数据和所有现有中文文案。
- `answers`、`scores`、`step` 和 `selected` 状态。
- 选择答案时先撤销旧答案得分、再累计新答案得分的逻辑。
- `topPrinciples()` 的最高分与并列判断逻辑。
- 保存海报和白皮书入口的行为。

### 新增视觉数据

在每个价值配置中增加或复用以下视觉字段：

- `pattern`: 对应 Base64 纹样数据地址。
- `accent`: 对应的主视觉仍统一指向墨青，价值差异主要由纹样表达。
- `sealLabel`: 结果章标使用的单字“真 / 善 / 美 / 爱 / 福”。

纹样资源在页面初始化时预加载。用户进入结果页前已有五题操作时间，正常情况下资源已完成解码。

## 异常与降级

- 某一纹样解码失败时，该区域回退为纸白或宣纸米平面，不阻断答题、计分和海报生成。
- Canvas 绘制时若纹样图片尚未完成加载，先等待预加载 Promise；加载失败则生成无纹样的合规海报。
- 不通过纹样传达唯一语义，价值名称和反馈文本始终可见。
- 页面不依赖远程字体、图片、脚本或网络请求。

## 自包含交付

- 将实际使用的盘长、回纹、如意、卷草、方胜和水波 PNG 转为 Base64 数据地址写入 HTML。
- 删除旧封面大图后再嵌入纹样，避免文件体积无意义增长。
- 保持最终 HTML 可在断网、`file://` 和普通现代浏览器中运行。
- 交付前检查不存在 `http://`、`https://`、外部样式表或远程字体依赖。

## 可访问性与交互状态

- 所有按钮触控高度至少 40px。
- 选项提供默认、悬停、键盘焦点、选中和弱化状态。
- 焦点状态使用墨青外框与纸色间隔，不使用浏览器默认蓝色。
- 颜色之外同时使用边界、文字和章标表达选中或最高分状态。
- 支持 `prefers-reduced-motion`，状态切换只使用 180ms 以内的透明度和位移动画。

## 验收标准

1. 封面、五个答题状态和结果页全部采用 v0.3 纸色、墨青、朱砂、鎏金视觉语言。
2. 页面不再出现现有五色渐变、彩色光斑、方格纸背景和旧关键词位图。
3. 每个反馈板块最多出现一个纹样，且与该选项第一价值一致。
4. 其他答案在选中后变浅但仍能重新选择，改选后分数与反馈同步更新。
5. 单一最高分和双关键词并列结果都能生成正确海报。
6. 保存的 PNG 为 1080×1920，并包含对应价值纹样或并列盘长纹。
7. `320×640`、`390×780`、`430×860` 三个视口无横向滚动、文字重叠或按钮遮挡。
8. 最终 HTML 无远程依赖，可通过 `file://` 完整运行。
9. 不修改题目文案、选项文案、计分和白皮书入口行为。

## 验证方案

- 静态检查：HTML 语法、无远程 URL、纹样数据地址存在、文件体积记录。
- 交互检查：逐题选择、同题改选、下一题、最终结果、保存海报、白皮书入口。
- 分支检查：分别构造五个单一最高分结果和至少一个并列结果。
- 视觉检查：三个移动视口截图，检查纹样透明度、长题换行、选项弱化、结果海报和底部操作。
- Canvas 检查：输出图片尺寸为 1080×1920，非空白，并包含可见但克制的纹样像素。
