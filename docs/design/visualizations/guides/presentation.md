# 灯塔演示制作细则

从[灯塔演示](../lantern/presentation.html)查看灯塔汇报的页面结构，它与[灯塔周报](../lantern/report.html)使用同源虚构聚合样例。按真实汇报任务组织页面，图表选型和数据表达遵守[图表制作指南](chart-workflow.md)。

需要其他叙事方式时，按[演示版式目录](presentation-catalog.md)查阅[第三方 19 页中文演示参考](../presentations/presentation.zh.html)。其中的页数、行业文案与原项目注释用于参考，灯塔 UI 开发先读取平台契约和目标组件。

## 参考演示的画布与文字

- 设计画布为 1600 × 900，以 16∶9 等比缩放。
- 内容区建议左右各 72px，上 64px，下 72px，来源与页码保留独立页脚区。
- 标题使用灯塔中文衬线字体回退，正文、图例、坐标和控件使用系统中文无衬线字体。
- 页面标题建议 56–96px，正文 22–28px，图例和坐标 20–24px，来源与页码 16–18px。最终按 1280×720 与实际投影距离复核。

## 全套颜色角色

颜色事实源为[Classic Amber 颜色系统](../../lighthouse-classic-amber-visual-spec.html#color)，实现由[共享 tokens](../tokens.css)提供。

常规页面使用暖纸背景 #F3EFE0，正文采用墨色 #2C2C2C。主要数据用琥珀 #D97706，辅助数据用黄铜 #9B7A4C。小字号琥珀文字用 #9B5C14，辅助小字用 #806744。风险与错误采用对应语义角色。

重点页面可使用由墨色派生的深色表面、暖纸反色正文，并校准琥珀和黄铜在该表面上的明度。网格、坐标和参考线保持中性层级。

多序列通过名称、位置、标记或实虚线共同区分。正文和小标签至少达到 4.5∶1 对比度，关键数据边界与大字至少达到 3∶1。较浅的填充配合清楚的边界和精确读数，重点同时从标题、结构或标记中表达。

## 翻页、图表与打印

前后方向键、PageUp/PageDown、Home/End、可见页码和 ?slide=N 定位应可用。焦点位于输入框或图表组件时，由该组件处理自身键盘操作。

图表在页面首次激活时初始化并播放，返回页面可保留已经完成的状态。减少动效偏好下显示静态终态。计时器、观察器和图表实例随页面生命周期清理。

打印时一张幻灯片对应一页，全部图表预先初始化，隐藏导航控件并保留来源与页码。按实际打印预览逐页检查尺寸、边缘、换行和图表完整性。

## 数据与交付

每页标题、正文、大数字、图例、悬停提示和无障碍描述保持同一口径，注明时间、单位、样本与计算方式。缺少数据时可用清楚的文字页、删去相关模块，或将待补数据写入交付说明。

复制模板时保留本地脚本的相对位置。图表依赖和系统字体回退支持离线浏览，另存目录后仍需直接打开验收。

交付前在 1600×900、1280×720、手机横屏和浏览器打印中检查。导出 PDF 后确认文本、图表和页码完整。可参考[调研演示示例](../presentations/lenny-2026-survey.zh.html)的内容组织与来源标注。
