# 灯塔演示版式目录

灯塔汇报先看[灯塔演示](../lantern/presentation.html)，它与[灯塔周报](../lantern/report.html)使用同源虚构聚合样例，便于核对同一组数据在两种输出中的读数和叙事。

需要扩展版式时，从[第三方演示入口](../presentations/index.html)打开 [19 页 Classic Amber 中文参考](../presentations/presentation.zh.html)。以下十类版式记录该参考的组织方式，可按汇报内容选读。

页内图表从[当前图型](../index.html)按数据形状选择，全套页面沿用[灯塔颜色系统](../../lighthouse-classic-amber-visual-spec.html#color)与[图表制作规则](chart-workflow.md)。

| 编号 | 版式 | 适合的内容 | 图表容量 |
| --- | --- | --- | --- |
| P01 | 封面 | 主题、时间、阅读范围 | 0–1 张主图 |
| P02 | 目录 | 章节导航 | 文字为主 |
| P03 | 章节页 | 交代一个问题或阶段 | 0–1 张 |
| P04 | 标题与单图 | 一个有证据支持的结论 | 1 张主图 |
| P05 | 大数字结论 | 单个指标及含义 | 0–1 张比较图 |
| P06 | 四指标总览 | 同一主题的相关指标 | 4 个小图或指标 |
| P07 | 双图比较 | 对象、时期或两组证据 | 2 张 |
| P08 | 通栏图表 | 时间序列、宽表、高密度关系 | 1 张宽图 |
| P09 | 结论与行动 | 总结证据，提出行动或待确认项 | 0–1 张 |
| P10 | 阅读说明与来源 | 样本、方法、限制和引用 | 文字为主 |

## 使用顺序

1. 写逐页提纲，确定每页的主要问题和结论，标出对应数据及来源。
2. 为需要证据的页面选择图型。版式决定内容关系，图型取决于数据与阅读任务。
3. 直接比较可重复使用同类图形和尺度，保持单位、日期和统计分母一致。
4. 使用共享的浅色、深色表面与琥珀、黄铜数据角色，通过标题、布局、标注与对比建立重点。[图表颜色角色](../index.html#colors)
5. 替换演示数字、来源、结论、图例和无障碍说明，再按最终输出尺寸复核。

HTML 演示支持翻页和浏览器打印为 PDF。交付说明写明实际文件格式，需要可编辑幻灯片时按指定格式另行制作并复核。[制作与交互细则](presentation.md)

模板结构和图形来源于 Lieflat Charts，灯塔维护 Classic Amber 适配与本页说明。[来源与许可](../README.md#来源与许可)
