# 灯塔报告版式目录

灯塔汇报先看[灯塔周报](../lantern/report.html)，它与[灯塔演示](../lantern/presentation.html)使用同源虚构聚合样例。开发与交付时按真实数据替换样例，核对指标、趋势与排名之间的关系。

[第三方报告目录](../reports/index.html)提供 12 套整页中文参考，保留不同的叙事顺序、版心与信息密度。其颜色采用[灯塔 Classic Amber 颜色系统](../../lighthouse-classic-amber-visual-spec.html#color)，页内图表按[图型清单](../manifest.json)和[制作指南](chart-workflow.md)选读。

## 使用与复核

复制所选的整份 HTML 作为起点，保留版心宽度、主网格、章节顺序和图表槽位关系。根据真实内容替换标题、正文、数据、图例、来源及注释，缺少依据的次要模块可删除。

需要更换图型时，在目录中锁定能表达数据的模板，再接入对应槽位。整份报告使用共享颜色角色，数据强调、反色区块与文字层级保持一致。[图表颜色角色](../index.html#colors)

模板采用本地资源和系统字体回退，复制到其他目录时同步核对依赖路径。宽图可在手机上提供局部浏览，整页保持清楚的阅读顺序。定尺卡片内容过多时调整内容或选择更适合的版式。

最终检查桌面、手机、键盘、离线打开及需要的打印或导出。正文与小标签至少达到 4.5∶1 对比度，大字及关键数据边界至少达到 3∶1，并通过名称、标记或布局辅助识别。

[R04 财务报告示例](../reports/r04-financial-report.zh.html)展示了月报版式如何适配另一类业务内容。模板结构来源于 Lieflat Charts，灯塔维护 Classic Amber 主题和本页说明。[来源与许可](../README.md#来源与许可)
