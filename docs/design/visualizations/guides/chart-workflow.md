# 灯塔图表制作指南

本指南供开发者与编程 AI 实现灯塔图表 UI 时使用。图表采用 [Classic Amber 颜色系统](../../lighthouse-classic-amber-visual-spec.html#color)，在[开发选型目录](../index.html#catalog)按用途查找缩略图、适用场景和复用状态。

## 按需读取实现

1. 从[设计系统索引](../../README.md)确认平台 token、基础组件与页面模式。
2. 读本指南的数据与图表规则，再从任务目录选择图型编号。
3. 查当前工作分支 `src/` 中的实际导出。已有共享组件按接口复用，页面内实现先核对业务依赖，参考 HTML 需要适配为页面组件。
4. 只进入选中图型的预览与对应绘制代码。示例数据、原项目注释、旧配色名称和来源归档用于解释模板；灯塔的颜色、权限和数据口径分别由视觉规范、业务授权逻辑和接口契约确定。

图库提供独立 HTML 参考图型。灯塔 1.6.0 的后台页面已使用[访问日历](../../../../src/app/admin/analytics/VisitHeatmap.tsx)、[PV/UV 趋势](../../../../src/app/admin/analytics/VisitTrend.tsx)和[员工榜单](../../../../src/app/admin/analytics/EmployeeRankings.tsx)。复用这些页面组件时，先核对访问统计的数据口径和查询权限。

## 先确定阅读任务

每张图回答一个问题，注明观测粒度、时间范围、指标、单位和分母。日常看板重点是读数、比较和发现异常，专题复盘可以提供更完整的事件、注释与关系。

| 交付任务 | 起点 |
| --- | --- |
| 单张图、看板中的图表 | 从[图表目录](../index.html#catalog)按用途和数据形状选型 |
| 灯塔可翻页汇报 | 从[灯塔演示](../lantern/presentation.html)查看虚构聚合样例，先写逐页提纲 |
| 灯塔整页报告 | 从[灯塔周报](../lantern/report.html)查看同源样例与读数关系 |
| 额外的演示、复盘或数据海报版式 | 按需要查[第三方演示参考](../presentations/index.html)或[第三方报告参考](../reports/index.html) |

用户提供的版式截图用于理解结构和阅读节奏。数据与结论从本次材料或已确认的数据源取得。

比较能承载该数据的候选，记录采用的编号、预览文件和理由。类别、日期、数值和关系的真实粒度决定图型，名称中的行业词只是示例场景。

| [一年内的每日数量](../index.html#calendar) | [L17 日历热力图](../gallery/lupi-gallery.html#L17)，明确实际日期范围与缺失日 |

每个点、格、单位刻度和连线都应有可说明的含义。数据量很少时选择更简单的图形。超出当前地图范围的点位、城市或轨迹，先确认相应的地理数据与表达方式。

## 一套 Classic Amber 颜色角色

颜色的事实源为[视觉规范的颜色系统](../../lighthouse-classic-amber-visual-spec.html#color)，离线预览入口为[图库 tokens](../tokens.css)。生产 UI 引用当前组件作用域内的语义 CSS token，并核对图表数据角色。已有 `[data-lh-v3]` 页面覆盖值见[平台 tokens 的作用域说明](../../tokens.md#color-authority-for-ui-development)。页面、字体和交互同时遵守灯塔的平台规范。

| 角色 | 使用方法 |
| --- | --- |
| 页面与绘图区 | 暖纸底色 #F3EFE0，浅色图表使用平台卡片表面。网格、坐标和参考线使用墨色派生的中性层级。 |
| 文字 | 主文本 #2C2C2C。小字号琥珀文字使用 #9B5C14，辅助小字使用 #806744。 |
| 数据与重点 | 主要数据使用琥珀 #D97706，辅助序列使用黄铜 #9B7A4C。需要的深浅阶从这两种角色派生。 |
| 深色图表 | 背景使用墨色派生的深色表面，正文使用暖纸反色。数据重点仍由琥珀、黄铜派生，按深色背景校准明度。 |
| 风险与错误 | #B85C46 用于风险或错误，小字号相关文字使用 #965040。 |
| 内容辅助色 | 求真、尽善、大爱等价值标签颜色用于对应内容标签，图表序列继续使用上述数据角色。 |

有序数量可以使用同一数据角色的明度梯，并标清从小到大的含义。多序列或类别同时用名称、位置、点形或实虚线区分。例如 PV 用琥珀实线，UV 用黄铜虚线，图例和逐日读数写出完整名称。

正文和小标签与背景的对比度至少 4.5∶1，大字及关键数据边界至少 3∶1。小字号文本和细线优先使用相应的深色文字角色。较浅的数据填充搭配清楚的边界、标记或精确读数。选中状态、异常和图例同时提供文字或形状线索。

## 接入数据与交互

1. 先核对当前分支可复用实现，再从[图型清单](../manifest.json)打开所选预览，按模板编号或 SVG、Canvas 容器 ID 找到绘制与交互代码。
2. 确认聚合方式、单位、时间范围和缺失值，替换标题、图例、标注、悬停提示、无障碍描述与来源。
3. 接入共享颜色角色，保持数值与几何的关系。柱长从零点比较，面积按面积编码，单位点阵说明一个单位代表什么，时间序列按实际日期排列。
4. 区分真实零值、未采集、读取失败和部分覆盖。线图缺失段留空，跨日去重指标采用对应期间的计算结果。
5. 保留有用途的悬停、点击、固定和重播，提供键盘入口、文本读数或数据表。手机支持点按和图内浏览。
6. 减少动效偏好下显示稳定终态，清理离页后的计时器、观察器和图表实例。打印或导出前初始化全部需要显示的图。

标题写清问题或有数据支持的结论。副标题提供日期、单位、分母和图例解释。标签过密时通过筛选、局部滚动、简化注释或换图提高可读性。

## 离线交付与复核

图表运行库和地图数据使用图库内的相对路径，字体采用系统中文回退。复制模板时一并保留依赖，并按交付目录重新核对链接。

- 数据总量、单位、样本和比例分母与材料一致。
- 图形位置、长度、面积、颜色和图例均表达真实数据。
- 标题、正文、标注、悬停提示和文本读数采用同一口径。
- 桌面、手机、键盘、减少动效和需要的打印模式可用。
- 本地直接打开可访问全部资源，页面无脚本异常，精确数据可读取。
- 保留模板编号、数据来源和[许可说明](../README.md#来源与许可)。

[完整示例](../index.html#examples)展示了从单图到报告、演示的组织方式。图形与实现谱系保存在[来源目录](../source/catalog.md)，灯塔维护本页规则、目录和视觉适配。
