# 离线地图轮廓

美国州级数据取自 Apache ECharts 官方示例的固定提交。世界国家级数据取自 Apache ECharts 4.9.0 的地图文件。DATA.json 记录源地址、原文件 SHA-256 和本地脚本 SHA-256。

为支持直接打开 HTML，本地 JavaScript 文件将原 GeoJSON 对象写入 window.LH_MAP_DATA。轮廓与坐标保持来源数据，演示指标保留上游样例。

许可见 echarts-examples-LICENSE.txt、echarts4-LICENSE.txt 与 echarts4-NOTICE.txt。当前页面使用已有 ECharts 6.1.0 运行库绘制两份地理数据。
