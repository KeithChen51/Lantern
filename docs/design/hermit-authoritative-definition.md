## 产品边界

路引是汽车售后服务文化领域的内置 AI 助手，也是灯塔知识中台的使用示范：用户提出现场问题、找到原则与案例、结合自己的材料形成下一步判断。

- 回答直接留在对话中，不设独立“产物／成果”工作台。
- 推荐用户有权访问的知识文档，在路引页内阅读。知识的发布、版本和访问权限仍由中台管理。
- Harness、模型名、工具协议属于实现细节，不进入页面导航。
- 本次不增加复制、修改问题、评价等回答操作；文档阅读与引用操作沿用现有流程。

## 起步与会话

首屏将路引身份、欢迎语、输入框和三张场景卡组合为一个居中操作区域。顶部右侧提供新对话、历史对话。开始对话后，用紧凑会话栏显示身份与标题，输入框固定在工作区底部。

| 场景卡 | 作用 | 点击结果 |
| --- | --- | --- |
| 找知识依据 | 查找相关原则与规范 | 带入可编辑草稿，聚焦输入，不自动发送 |
| 对照相似案例 | 对照类似门店情境与经验 | 带入可编辑草稿，聚焦输入，不自动发送 |
| 结合材料分析 | 结合知识理解自己的材料 | 带入可编辑草稿，用户继续添加材料 |

新对话建立独立会话上下文，不删除旧对话。切换应取消旧请求并隔离其异步回包、上传任务和错误状态。生成期间允许编辑下一条草稿，只限制再次发送。

## 输入与文件

- 写作区域在上，底部只保留左侧加号与右侧发送／停止；加号悬浮提示“添加文件和更多内容”。点击浮层可添加本地文件、灯塔知识文件或平台已发布 Skill，格式和大小限制在浮层中说明。
- 知识文件与 Skill 支持搜索和选择，分别最多一项，可与本地文件一起使用。已选内容显示为可移除标签，替换或移除不清空草稿。
- Skill 首期按实际读取的方法辅助回答，不执行脚本或导出文件。平台权限、发布状态和有效期由服务器重新校验；不会读取个人 Skill 目录。
- **发送前附件**紧贴输入框上方、左对齐，使用紧凑文件卡，多文件横排且可换行。卡片包含图标、可截断文件名、状态／大小与右上移除按钮；完整文件名仍可访问。不再使用占满输入宽度的独立长横栏。
- 上传中可取消、失败可重试、发送前可移除。移除文件或文档上下文不清空草稿。
- 发送后的附件、知识文档和技能展示在对应用户消息下方，输入区只保留待发送材料。已发送材料仍可参与后续回答，最新消息中的材料卡允许移除后续引用，保留原消息记录；失败重试不得混入下一条草稿新选的材料。
- 首批接受 PDF、DOCX、TXT、Markdown；运行限制为单文件 10 MB、每个会话最多 5 个，解析与保留期限以后端配置为准。
- 未完成或失败的附件不能随消息发送；文件属于当前用户的对话参考，不自动发布到中台。
- 输入聚焦保持默认浅色边界与阴影，不增加橙色描边、光晕或 textarea 内框；文本光标指示输入位置，按钮与链接继续保留键盘可见焦点。

## 执行与恢复

| 状态 | 显示与行为 |
| --- | --- |
| 请求开始 | 简短说明正在准备回答 |
| 实际查找知识 | 根据真实目录／索引调用显示正在查找 |
| 实际阅读 | 根据真实文件／文档读取显示正在阅读 |
| 生成正文 | 真实文本流到达后显示正在整理回答 |
| 失败 | 在对应回答位置说明失败，重试该次回答；不重复用户消息，不将旧问题填回当前草稿 |
| 停止 | 明确标注已停止，保留已有内容和下一条草稿 |

阶段可以重复或跳过，不是预设步骤条。不得使用计时器伪造执行进展，不展示内部推理。原型的延迟跳转仅用于演示。

## 历史对话

- 使用页内抽屉，不新增常驻全局会话侧栏。
- 列表包含标题、摘要、更新时间和加载更多；有加载、空、失败与重试状态。
- 正式账号可查看、恢复、继续自己的对话。由服务端当前身份授权，不能接受客户端指定其他账号；访客展示登录提示。
- 恢复消息与可信的引用／推荐、仍有效且有权限的附件和文档上下文；失效材料明确提示，不继续发送其 ID。
- 旧记录没有来源元数据时仅恢复文本，不伪造引用；失败与停止不能伪装为完成。
- 抽屉支持 Escape、焦点圈定和关闭后焦点返回触发入口；窄屏保持可达。

## 阅读与滚动

顶部、消息区、输入区和阅读区采用稳定容器，无需额外可见边框。对话与文档正文分别滚动，不撑高整页。阅读器标题、关闭／返回与引用操作保持可见。

推荐卡打开页内阅读器，默认从文首开始；切换文档只重置文档滚动。桌面并排，窄屏进入页内阅读视图，返回保留对话。引用本文沿用现有关闭阅读区并将文档放入输入上下文的行为。

用户向上阅读时，新文本不能强制拉回底部；提供“查看最新回复”。文档下架、无权限或加载失败时保留对话并提供恢复操作，不绕过中台权限。

## 实现约束

组件契约见 [路引标准组件](hermit-components.md)。复用 Classic Amber tokens、本地图标与字体；动效仅用于局部反馈，支持减少动态偏好。不得因视觉调整削弱知识索引、来源验证、渐进式读取、提示词、权限或聊天行为。

代码验收包括问答、文件上传、失败重试、停止、历史恢复、跨账号隔离、窄屏、键盘和独立滚动。开发完成、PR、集成与部署分别记录，设计确认不等于已发布。
