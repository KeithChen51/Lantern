# Classic Amber V3 页面迁移记录

更新：2026-10-04。关联 [Issue #13](https://github.com/KeithChen51/Lantern/issues/13)。

## 当前基线

[Figma V3 完整设计系统](https://www.figma.com/design/pTRlWu7oWNW7LqLCFr9262?node-id=121-983) 是本轮视觉基线。本心首页保留原有设计，灯塔导航的结构与定位保留。其他已批准页面使用 `PageHeading` 和 `main[data-lh-v3]`，由 `src/app/visual-v3.css` 约束颜色、标题、布局和状态。

## 已迁移范围

| 页面 | 变化 |
| --- | --- |
| 镜鉴目录与案例详情 | 统一标题、卡片、元信息与阅读区域；方法说明按需展开。 |
| 笃行目录与详情 | 案例先比较再进入阅读；同排卡片等高，保留真实案例和路由。 |
| 启航 | 统一页头、封面与入口卡片。 |
| 搜索与知识阅读 | 对齐工具栏、结果行、正文和状态。 |
| 反馈 | 统一表单、选项、校验和成功状态。 |
| 后台入口与案例编辑 | 统一页头、表单、上传与操作区域，保留认证和保存逻辑。 |
| 路引 | 保留独立身份标识；回答直接留在对话中；支持上传与知识文档页内阅读。手机阅读器替换对话区域，返回保留会话。 |

桌面标题为 44/56，左边距 128px、顶部 64px；手机为 32/44，左右 20px、顶部 96px。展开导航后内容避让到 288px。本心首页不套用这些页面重排规则。共创及其他未出现在本轮批准原型中的工作流没有重新设计。

## 验证记录

- 143 项测试通过，ESLint、TypeScript 和生产构建通过。
- 生产构建使用已有知识向量：`HERMIT_KNOWLEDGE_USE_PREBUILT=true`，未重新请求 embedding 服务。
- 在 1440px 和 390px 宽度检查镜鉴、笃行、启航、搜索、反馈、后台、路引及本心；无横向溢出、空白页、缺失图片或未捕获页面异常。
- 实际验证 TXT 上传和移除、后台本地登录、导航展开收起及手机菜单。
- 用受控响应验证对话流、推荐文档打开、手机返回保留会话，以及反馈成功状态；这些不代表真实模型或外部反馈服务已联调。
- 独立验收环境未配置业务数据库与 DSH 模型服务，后台列表显示配置错误状态；没有执行真实案例保存、发布或部署。

## 清理与边界

移除 5 个废弃配色/组件探索 HTML，保留当前 Classic Amber 视觉规范、本心品牌参考、活动 H5 与印刷资产。设计入口、tokens、组件、页面模式和路引权威定义同步指向 V3。历史文件可从 Git 找回，云端 Figma 未删除。

后续新增页面应复用共享标题、语义颜色与页面模式；不能把本轮视觉验收理解为数据库、权限、模型服务或部署验收。
