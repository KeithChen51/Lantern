# 经销商会前预热 H5 首页回退与最终分享页设计规格

日期：2026-07-17
状态：设计已确认，待实施

## 背景

现有 H5 已完成五题互动、答案改选、价值计分、海报生成、保存和白皮书入口。上一轮改版将 v0.3 品牌视觉同时应用到了首页、答题页和分享页，但本轮确认：首页应恢复为原版；分享页则需要同时承担“个人服务理念名片”和“完整服务理念框架传播”两项任务。

## 目标

1. 首页恢复到仓库基线版本的视觉、内容和排版。
2. 五题答题流程、改选行为和现有计分方式保持不变。
3. 分享页突出一个个人主关键词，同时完整呈现其余四项理念及对应诠释。
4. 支持用户自定义姓名或门店署名，但不接入、查询或上传任何数据。
5. 继续输出可保存的 1080 x 1920 PNG 海报，并保持单 HTML 离线可用。

## 不做

- 不修改五道题目、选项、反馈文案和每个选项对应的理念计分。
- 不增加账号、门店库、用户资料、接口请求或埋点。
- 不显示五项得分、关注顺序、排名或进度条。
- 不增加“生成海报”或“重新体验”按钮。
- 不修改白皮书内容及其现有链接目标。

## 页面流程

### 1. 首页

首页完整恢复到当前 Git 基线版本，包含：

- 原版内嵌关键词拼字海报及“服务理念关键词”角标。
- “参悟案例”“5 个判断”两个信息标签。
- 标题：“一单养护，怎样做成长期信任？”
- 引导文案：“客户不是不接受服务，而是不接受被推销。真正难的是：把该推荐的讲清楚，把不该赚的钱停下来。”
- 原版底部开始按钮及其进入第一题的行为。

首页不采用本轮结果海报的“一核四章”结构，也不使用结果页的墨青主关键词色块。

### 2. 答题页

- 保持现有五题、进度、反馈和按钮行为。
- 用户选中一个答案后，其他答案降低视觉对比，但仍可点击改选。
- 改选时先撤销上一答案的计分，再累加新答案计分。
- 最后一题完成后直接进入结果页，不增加中间确认页。

### 3. 最终分享页

结果页进入后立即显示完整海报，不要求用户再次点击生成。

页面从上到下为：

1. 1080 x 1920 海报预览。
2. 一个可选的“署名”文本输入框。
3. 主按钮“保存服务关键词海报”。
4. 次按钮“查看服务理念升级白皮书”。

结果页不提供重新答题入口。

## 主关键词规则

1. 五题完成后计算五项理念总分。
2. 若只有一项最高分，该项直接成为主关键词。
3. 若两项或多项并列最高分，只在并列最高分集合中随机选取一项。
4. 随机选择只在首次进入结果页时执行一次，并保存为当前结果状态。
5. 修改署名、重新绘制海报或多次保存时不得再次随机，确保当前结果页中的主关键词稳定。

随机结果不改变各理念的得分，也不在海报中表达为权威判断；它只用于确定本次分享海报的视觉主关键词。

## 分享海报信息结构

采用已确认的“一核四章”版式，并使用最终微调比例。

### 第一层：个人主关键词

- 位于海报上半部，是唯一使用墨青实色块的内容区。
- 显示“我的服务关键词”、主关键词和对应的一句理念诠释。
- 主关键词是全海报最大文字。
- 主关键词对应纹样可作为低透明度辅助，不遮挡文字。

### 第二层：完整服务理念

- 位于主关键词下方，以 2 x 2 结构呈现其余四项理念。
- 四项均显示关键词和完整的一句诠释。
- 四项不显示分数、排序、序号或进度。
- 四项标题字号约为主关键词的四分之一。
- 取消厚重卡片底色，只使用纸色、留白和细分隔线，降低视觉重量但保持可读。

### 第三层：品牌与署名

- 顶部保留精诚服务品牌识别、印章或题签信息。
- 底部显示自由署名和必要的品牌辅助文案。
- 署名不抢占主关键词与五项理念的阅读层级。

## 五项理念固定诠释

| 关键词 | 海报诠释 |
| --- | --- |
| 求真 | 把事实讲清，是信任最稳的起点。 |
| 尽善 | 在现实约束中，把长期信任放在前面。 |
| 致美 | 专业不只在结果里，也在交付细节里。 |
| 大爱 | 先看见人的处境，再回到可承担的解法。 |
| 幸福 | 让安心、尊重和可持续，进入每一次服务。 |

无论哪一项成为主关键词，五项理念使用同一组固定诠释，不根据答题路径动态拼接新文案。

## 署名交互

- 结果页提供一个可选文本框，标签为“署名”，提示文案为“填写姓名或门店”。
- 姓名和门店共用一个输入框，不要求用户先选择类型。
- 输入值仅保存在当前页面内存中，不写入本地存储、不上传、不发起校验请求。
- 去除输入值首尾空格，并限制为最多 16 个可见字符，避免海报溢出。
- 未填写或清空时，海报显示默认署名“精诚服务践行者”。
- 用户输入后以短延迟方式自动重绘海报，不出现“生成”按钮。
- 点击保存时必须使用输入框中的最新有效署名。

## 视觉规则

分享页和生成海报继续遵循《精诚服务视觉识别手册 v0.3》：

- 墨青 `#183A34`
- 烟墨黑 `#0B130F`
- 宣纸米 `#F3E9D7`
- 纸白 `#FFFDF8`
- 鎏金线 `#BFA76A`
- 朱砂印 `#722912`

传统纹样以低透明度辅助构图，不得覆盖正文或制造五项理念之间的等级暗示。分享页避免得分图表、彩色进度条、条形统计和测试报告式视觉。

## 单文件与异常处理

- 原版首页拼字图、v0.3 纹样及必要图片继续以 Base64 内嵌，分享单个 HTML 时不丢失资源。
- 页面不得依赖外部字体、样式表、脚本或网络请求。
- 某个纹样解码失败时，使用纸色平面背景继续生成海报，不阻断结果页。
- 署名重绘失败时保留上一张有效海报；保存按钮不得下载空白图片。
- 海报生成期间保存按钮处于不可用状态，完成后恢复。

## 响应式与可访问性

- 仅提供手机端体验，覆盖 320、390、430 像素宽度。
- 页面不得出现横向滚动，海报按固定 9:16 比例缩放。
- 署名输入框有可见标签、键盘焦点状态和明确的最大长度。
- 所有按钮保持可见焦点状态；禁用状态不能只依赖颜色表达。
- 海报图片 `alt` 包含当前主关键词，不包含未填写的个人信息。

## 验收标准

1. 首页视觉、图片、标签、标题、文案和开始按钮与 Git 基线版本一致。
2. 五题可以正常进入、选择、改选和完成，其他选项变浅后仍可点击。
3. 单一最高分时，正确理念成为主关键词。
4. 并列最高分时，主关键词只可能来自并列集合；进入结果页后保持稳定。
5. 分享海报不显示得分、排名、关注顺序或进度条。
6. 主关键词明显突出；其余四项更小，但每项关键词和诠释均完整可读。
7. 署名支持姓名或门店自由文本，不填时显示“精诚服务践行者”。
8. 修改署名后海报自动更新，保存结果包含最新署名。
9. 保存图片尺寸为 1080 x 1920，图片非空白且文字不溢出。
10. 白皮书入口保持可用，不出现“生成海报”或“重新体验”按钮。
11. 320、390、430 像素宽度均无横向溢出和内容遮挡。
12. 断网并通过 `file://` 打开时，首页图片、纹样、答题和海报保存均可用。

## 验证范围

- 静态检查：无远程资源、原版首页标记存在、五项固定诠释存在、署名字段及最大长度存在。
- 交互检查：逐题选择、同题改选、单一结果、并列随机结果、署名更新、连续保存、白皮书入口。
- 海报检查：1080 x 1920、非空白、五项诠释完整、长署名不溢出。
- 视口检查：320 x 640、390 x 780、430 x 860。
