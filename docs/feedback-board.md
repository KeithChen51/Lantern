# 员工建议广场

开发记录：[#138](https://github.com/KeithChen51/Lantern/issues/138)。该记录只跟踪软件开发；用户的建议、互动、处理记录和通知全部存储在应用 MySQL 数据库，不创建或关联代码仓库 Issue。

## 使用与范围

从“我的 → 建议广场”进入，首页以紧凑横向卡片展示同事的建议标题、一行正文摘要、作者与互动数，点击卡片主内容进入详情阅读和讨论。标题旁提供发布和通知入口。浏览视图包含“最新”“热门”“我参与的”，分类通过标签切换；处理状态与“只看我发起的”收在按需展开的筛选中。热门按点赞数排序；“我参与的”包含自己发起、当前点赞或评论过的建议，可与其他筛选组合。取消点赞后，若没有发起或评论该建议，它会从自己的参与列表移除。

列表可直接点赞或取消，点击评论数进入详情的讨论区。有管理员处理时，桌面卡片以简短提示呈现；手机以标题和互动为主，完整回应在详情查看，没有回应时不虚构进展。接口正文摘要最多 180 个 Unicode 字符，回应摘要最多 160 个；详情提供完整正文及回应历史。

点击发布入口后填写类型、标题和内容，相关页面与服务场景写在正文中。正文、评论、回复和处理说明都是纯文本，保留换行、安全转义；没有 Markdown、图片、附件、对象存储或邮件通知。

关闭发布窗口或按 Escape 会保留当前员工的草稿；同一浏览标签页刷新后仍可继续编辑，草稿有效期为 24 小时。成功发布或选择“放弃草稿”后清除，登录权限失效时同步清除。浏览器禁用存储时，草稿保留到当前页面关闭。

排序、分类、处理状态、我发起的及页码保存在列表地址中。从卡片进入详情后，页面返回入口和浏览器后退都会恢复原列表及阅读位置。评论数直接定位已加载的讨论区，点击“写评论”或回复时展开输入；收起保留文字，发送成功后定位新评论。空结果显示当前筛选条件，并提供清除状态和查看全部建议的操作。

四种类型：平台功能与体验、服务文化、内容与知识、其他。标题最多 100 字符，正文 4000 字符，评论和处理说明 2000 字符。作者从服务器认证身份获得，列表展示姓名，不展示工号和联系方式。

建议发布后立即在员工范围可见；每位员工可对每条建议点赞一次，也可取消。评论可回复同一建议内的评论。管理员隐藏不适当评论时保留占位，不向读者返回原文。

## 状态与处理

状态为待回应、评估中、已采纳、推进中、已落实、不采纳；允许跳步。已采纳表示认可方向，推进中表示已行动，已落实表示完成并解释结果。管理员每次处理都必须填写说明，可修改类型、状态并关联另一条站内建议。不能关联自身或不存在的建议。处理人、时间、前后状态和说明保留记录；并发管理员基于旧版本操作时返回冲突，刷新核对后再提交。

建议发起人在状态变化时收到站内通知，被回复者收到回复通知，不发送给操作人自己。通知在建议板块查看与标记已读，“我的”入口展示未读数；通知仅接收人可读和标记，平台管理员也不能通过接口查询其他人的通知。

详情以原帖和讨论为主，回应历史按需展开；管理员处理表单在仅管理员可见的折叠区域中，不占据普通员工的讨论位置。

## 身份与权限

页面与所有 API 都要求员工 Web 会话。访客模式不显示入口，直接访问也不返回建议内容。员工 CLI/MCP 凭据不能用于本板块。所有写操作校验同源和会话 CSRF，读取请求体后再次验证会话；请求体不能指定作者或替代服务器权限判断。

`feedback:manage` 只授予现有独立平台管理员角色。IAM 对应 `lighthouse_admin`，门户模式使用独立的 `PORTAL_PLATFORM_ADMIN_ROLE`；其值与知识管理员角色相同时不授予本能力。知识管理员不会自动获得处理建议权限。管理员写入使用短权限刷新窗口，无本地授予角色入口。

## 数据与交付

新增建议、点赞、评论、处理事件、通知表，关联现有员工 User 主键；无需导入旧外部 Issue。旧反馈客户端与配置入口移除。迁移为新增表和索引，不覆盖知识、聊天或已有用户数据。

社区信息流改版（[#144](https://github.com/KeithChen51/Lantern/issues/144)）沿用上述表结构，没有新增迁移、环境变量或依赖。列表摘要与参与筛选使用既有数据，不开放新的身份访问范围。

部署前备份数据库，执行 `npm run db:deploy` 后启动新应用；构建前执行 `npm run db:generate`。回滚应用可以恢复旧版本，但保留新增表和数据，不自动删除已经提交的建议。真实内网数据库、身份平台与部署仍需环境验收；本地测试不代表已部署。

## 验证

验收涵盖匿名/访客/员工/知识管理员/平台管理员边界、CSRF、并发点赞唯一性、管理员冲突、跨建议回复限制、通知归属、纯文本渲染、移动端与键盘操作。具体执行结果在开发 PR 中记录。
