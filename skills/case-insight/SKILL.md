### Skill 概述

case-insight skill 的核心目的是：从案例研究中提取有意义的洞察——识别认知冲突、分析分歧观点、综合基于证据的结论，为服务人员产出可行动的洞察。应用「真、善、美」文化框架解决复杂问题，建立正向能量循环。

#### 适用场景

- 分析客户服务场景，提炼洞察
- 识别案例材料中的冲突与矛盾
- 从复杂情境中提取可复用的决策框架
- 为汽车服务人员创建培训内容
- 将精诚服务文化 2.0 原则应用于真实情境

#### 冲突双门槛（必过，先于其他判断）

- **Gate 1 · 明确矛盾：**案例中必须有清晰、真实的矛盾（两难、对立或冲突）。无明确矛盾 → 不适合写参悟案例，说明原因并终止。
- **Gate 2 · 多路径并存：**矛盾中必须存在多个行动路径（至少两条），且每条路径都有各自成立的理由——每一方都「听起来有道理」。只有单一行动路径，或某条路径一望即错、结论一眼可判 → 不适合，说明原因并终止。

双门槛全部通过后，才继续以下判断。案例若价值取向与「求真、尽善、致美、大爱、幸福」冲突、或冲突一望可判无可沉淀模型，则判定为不适合。

### 实施工作流

#### Pre-Analysis Preparation · 分析前准备

- 研读精诚文化框架，理解求真、尽善、致美、大爱、幸福的内涵
- 回顾参考案例目录 6 篇，作为基线
- 用冲突双门槛评估案例质量：明确矛盾 + 多路径并存
- 判定是否合格：合格则进入下一阶段；不合格则说明原因并终止

#### Case Understanding · 案例理解

- 识别案例背景、主要人物、关键事件与结果
- 对照精诚文化 2.0 要求比对案例契合度
- 识别转折点与决策时刻
- 厘清案例中的冲突与争议，分析表面矛盾与深层系统性影响
- 价值判断：参悟内容与结论是否与五维一致；偏离则输出判断结论与修改建议，不生成案例

#### Insight Extraction · 洞察提取

- 应用五维分析，但选择性而非穷尽——先判定案例决策实际触及哪一两个维度，只分析这些
- 维度分析必须为「为何选这一方」补充新论证，绝不复述冲突/证据材料已确立的点
- 提取可复用思维框架：冲突是什么？存在哪些观点？为何选此观点？底层决策逻辑？
- 识别决策背后的能量循环；若存在正向闭环，在参悟结果中一两句点出，不单列清单

#### Case Content Generation · 案例内容生成

- 先做结构选型定讲述主轴，再做版式轮换定呈现形态
- 映射到必选 5 件：导读 / 情境引入 / 核心冲突 / 参悟过程及结果 / 知行合一
- 遵守语言风格四律、去模板化、写作纪律与自检清单
- 每部分必须补充新论证，绝不编造数据

### 语言风格四律

四律决定选词、句长与语气，与骨架规范同等严格，每篇生成都必须遵守。

##### 律一 通俗易懂，但不口语化

- 句子要短：单句尽量不超过 40 字，一句只讲一件事；长句拆成短句，用「因为/所以/但是」衔接
- 术语首次出现时补一句解释，如「坪效——单位面积能产出的价值」
- 具体代替抽象：写「张师傅蹲在屋檐下，看着外面的大太阳」，不写「员工处于环境不适状态」
- 禁用口语词与网络语：说白了、咱/咱们、整、搞、弄、贼、超、yyds、emmm，以及句尾的「吧/呢/呗/啦」
- 可以「我们/你」设问代入，但设问后必须给答案；正文不用感叹号抒情

##### 律二 简洁凝练，但说理鞭辟入里

- 每个判断句必须有支撑：断言之后紧跟机制、数据或因果链；裸断言不合格
- 说理走「现象 → 机制 → 边界」三步：摆事实，讲清为什么，最后点明什么情况下不成立
- 用逻辑词显形推理：「因为……所以……」「前提是……」「除非……」；禁止只并列不推理
- 无信息形容词一律删：极致、完美、深刻、非常重要、无比——删掉后意思不受损就删
- 数字与事实优先：写「等待时间从 40 分钟降至 15 分钟」，不写「体验得到极大提升」

##### 律三 情感色彩中立

- 描述处境用中性词：用「不满、犹豫、顾虑、失望」，不用「委屈、憋屈、崩溃、愤怒」——后者只允许出现在人物直接引语中
- 呈现对立双方时用词对称：不预设立场（用「从经营角度看成立，但忽略了……」）
- 感叹号只出现在直接引语，正文陈述一律句号
- 价值维度用做法与后果陈述，不抒情

##### 律四 用词不煽情

- 禁用夸张副词：极其、万分、无比、彻底、绝对、堪称、惊呆、震撼、爆棚、逆天（「严禁/必须」等规则性表述除外）
- 比喻只用于说理（把抽象变具体），不用于煽情（如「像刀扎一样难受」）
- 用结果事实代替情绪渲染：写「一次客诉，三个客服工时、十次公关解释」，不写「品牌形象遭受毁灭性打击」
- 结尾禁口号与排比抒情

#### 对照示例（同一意思，两种写法）

| 不合格 | 合格 |
| --- | --- |
| 说白了，坪效就是每平米能挣多少，咱不能瞎浪费。 | 坪效即单位面积产出的价值；为新服务划出面积，需要算清这笔账。 |
| 看着客户心酸的背影，我们怎能无动于衷？ | 客户的不满会直接转化为客诉成本，处理它比回避它更省资源。 |
| 极致完美的体验，无与伦比的专业水准。 | 等待时间从 40 分钟降至 15 分钟，返修率当月为 0。 |
| 部分门店唯利是图、丧尽天良。 | 部分门店在置换补贴申请中附加收购条件，压低了客户车辆收购价。 |
| 这样做是对的，因为它符合我们的服务理念。 | 客户购买的是「故障被修复」的结果——手段的风险，归组织实施手段的一方。 |

### 结构选型与版式轮换

骨架保证要素齐全；但同一副骨架套所有案例，会让每篇都长一个样。动笔前先判型——案例的「本性」决定用哪条讲述主轴、按什么顺序展开、分节标题叫什么。

#### 五种案例本性与讲述主轴（先判型，再选主轴）

| 本性 | 识别信号 | 讲述主轴 |
| --- | --- | --- |
| **两难选边型** | 存在两条或更多行动路径，每条都有成立的理由 | 站在选择现场 → 每条路径各自最强的理由 → 检验共享前提 → 做出选择 → 落地做法 |
| **边界型** | 争论焦点是「界限画在哪」 | 痛点场景 → 逐层划界（每层回答一个「到底算不算」）→ 落成可执行判断 |
| **病灶型** | 一件小事反复发生、没人说破 | 一件小事 → 追问三连（为什么没人管/反复/不敢）→ 断点在哪 → 制度修复 |
| **重构型** | 旧规则在真实场景里失效 | 旧规则当年的合理性 → 新场景如何让它失效 → 回到目的重新设计 → 新规则与代价 |
| **共生型** | 多方利益互相拉扯（厂商-门店、平台-商家） | 各方各算各的账 → 谁在替谁买单 → 重建利益结构 → 规则落地 |

#### 四种版式（判型选主轴，版式选形态，两者独立）

| 版式 | 形态 | 适合 |
| --- | --- | --- |
| **A 骨架式** | 内容词小标题分节推进 | 观点交锋清晰、信息层次多的案例 |
| **B 段落流** | 全篇无小标题、一条线讲到底 | 故事感强、主线单一的案例 |
| **C 问答式** | 以连续设问推进全文 | 「该不该/行不行」型决策案例 |
| **D 对话式** | 以当事人引语串起段落 | 场景冲突强烈的案例 |

### 去模板化（祛 AI 味）

AI 味主要来自「太工整」：段落都收尾、句子都对称、转折词成套出现。要求：

- **结构标签不外露：**卡点/定局/两边等分析词只用于构思，不进正文（导读/情境引入/核心冲突/参悟过程及结果/知行合一五个固定分节标签除外）
- **句式轮换：**摆理由、下判断、讲后果等动作在不同案例换写法——相邻两段不得用相同的句首发语词
- **套路句限用：**「不是……而是……/真正的……是……/表面上看……其实……/关键在于……」全文合计不超过 2 次，同类转折不连用
- **允许不「收尾」：**一段讲完事实就可以停，金句收尾段全文不超过 1 处
- **衔接靠事实：**上一段结尾的事实引出下一段的问题，禁止每段都以「所以/因此/这说明」开头
- **具体优先：**充电桩、饭盒、铭牌、45%……数字与实物优先于抽象词
- **人称克制：**全文「我们/你」代入句不超过 2 处，禁止「让我们……」开头

#### 必选 5 件 · 案例主体

- **导读（100–200 字）：**核心矛盾 + 最终解法一句话摘要；只摘要、不推演
- **情境引入（150–300 字）：**有时间地点、人物、动作、对话的小故事，结尾点出分歧触发点
- **核心冲突：**讲清多组冲突与各方观点，每个观点给 2–3 条最强理由，用事实与机制支撑
- **参悟过程及结果：**讲清「为什么最终选这个」与「最后的结果」，价值判断只引与决策直接绑定的 1–2 个文化维度
- **知行合一：**3 个反思问题指向「遇到类似情境怎么办」+ 1–3 条可执行动作

#### 写作纪律（反模式清单）

- 不做五维轮排（「从『真』的角度看……」×5 之类整段排比）
- 「不是……而是……」全文不超过 2 次
- 禁止警句收尾（「真正的服务，始于……」）
- 禁止跨案例复用句式与比喻
- 每个论点全文只出现一次，后文只引用、不重述
- 文化维度只引与决策直接绑定的 1–2 个
