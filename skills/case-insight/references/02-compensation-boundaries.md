# 如何应对客户不合理的赔偿诉求

案例本性：边界型

导读

客户因我们的服务过失要求赔偿——答应到什么程度，才算既负责任、又不失分寸？

客户提了一辆新车，进店做装潢时，因服务方过失发生了事故。车修好了，客户的诉求却没有停：耽误的时间、可能上涨的保费、二手车市场的贬值，连精神损失一起算上——「新车变成了事故车，比亚迪就该负责」。

门店认账：服务方全责，我们愿意给客户一个圆满的解决。但客户要求的赔偿明显超出了合理范围，满足不了。表面争的是「赔不赔」，真正的问题是「赔到什么程度」。

卡住我们的，其实是三个混淆：把「不让这个客户闹」当成「保护品牌声誉」；把「共情客户情绪」当成「满足一切诉求」；把自己当成「传声筒」。把这三个混淆拆开，边界就清楚了：

- **责任边界**——我们认的「错」，对应的是「恢复原状」的责任，不是「满足一切」的义务。
- **补偿边界**——赔的是可量化、可举证的损失：维修、代步费用有单据；误工、折旧、精神损失若纳入，也要有清晰依据佐证合理性。
- **信任边界**——在「合法、合理、合情」的范围内给方案，不牺牲广大正常客户的权益。
- **角色边界**——不做传声筒，做判断者：温和而坚定地建立预期。

这四重边界，是「求真」与「尽善」的合取：尊重事实与规则，同时在边界之内把善意传递到位。客户的情绪值得被理解，但我们的善意，要给在边界之内。

#### 回味三个问题

1. 听到一个「听起来过分」的诉求时，你的第一反应是恐惧，还是判断？
2. 你店里「为平息情绪而让步」的做法里，有哪些其实模糊了边界？
3. 如果客户以曝光相威胁，你判断「该不该坚持」的依据是什么？
