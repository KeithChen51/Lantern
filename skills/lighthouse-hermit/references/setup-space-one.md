# SPACE ONE 接入

将此 Skill 作为创建对话 Agent 的业务材料提交。管理员按平台支持的方式登记灯塔只读 MCP 或 OpenLink CLI，并确认工具运行环境能访问灯塔 HTTPS 站点。

- 厂端用户用自己的灯塔员工账号批准工具授权。
- 店端用户用自己的比亚迪汽车经销商账号批准工具授权，读取灯塔网页对经销商开放的已发布资料。

连接配置和 Skill 可以统一分发。每次查询使用发起者本人在灯塔批准的凭据。由用户本机运行工具时，使用其系统账号的安全凭据存储。由平台集中运行时，先验证各账号的授权、凭据、刷新和撤销都能按用户隔离，再开放使用。

联调时用厂端和店端试点账号分别核对 `auth status`，检索同一份公开资料，再用员工可见的内部资料验证店端权限。客户端安装与设备授权见[通用接入说明](setup-other-hosts.md)。
