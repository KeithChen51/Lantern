# 内置页面字体

英文和数字使用同源加载的 Inter 4.1 可变字体。中文正文优先使用系统字体，Windows 为微软雅黑 UI 或微软雅黑，苹果设备为苹方 SC。缺少系统中文字体时使用内置思源黑体。思源黑体、思源宋体与得意黑也可从同源 `/fonts/` 加载。思源宋体使用 Adobe 官方 2.003R 的完整 SC 可变 WOFF2（200–900），未做字形裁剪，支持知识资料后续新增汉字。原有思源黑体与得意黑文件保留。各目录附上游许可证，manifest.json 记录来源与 SHA-256。

构建前校验源码字体，standalone 准备后再次核对复制的字体和许可证；缺失、篡改或声明中使用 local() 将失败。更新字体必须同时更新来源和校验值。
